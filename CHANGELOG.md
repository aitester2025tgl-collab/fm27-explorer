# Changelog

## 1.0.0 — 2026-11-19

First public release.

- Import FM27 saves in the browser (Pyodide + fmsave); multiple saves and seasons stored locally.
- Players and clubs database with all attributes, hidden attributes and personality.
- Tactic view: built-in presets and tactics read from the save, roles per position, best XI and
  second options, weak-position flags, editable role weights.
- Role-driven scouting per position with key-attribute comparison against the current starter.
- Filters: max age, estimated price, wage, contract expiry, preferred foot, height, nationality,
  CA/PA, minimum fit; two-way sorting on every table.
- Estimated asking price and release clauses.
- Realistic mode (hides CA/PA and hidden attributes).
- English and Portuguese interface with a language switch (English by default).
